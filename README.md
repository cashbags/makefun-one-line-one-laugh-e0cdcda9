**One Line, One Laugh** — one phone setting, one pilot, one personal apology:

> I put my phone on airplane mode and immediately felt like I owed the pilot a personal apology.

94 characters, one line. It won a 66-game pairwise tournament over 12
candidates in empty lanes (DESIGN.md).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`
with no trailing newline. No clock, no randomness, no network.
